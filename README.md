# Планировщик меню и список продуктов (Android)

Учебный проект на Kotlin для планирования рациона на неделю и автоматического формирования списка покупок.

## Основные функции
- Составление меню по дням недели и приемам пищи (завтрак, обед, ужин).
- Автоматическое добавление ингредиентов блюда в список покупок.
- Отметка купленных продуктов и очистка списка.
- Сохранение данных в памяти телефона (SharedPreferences).
